## หลักการทำงาน

1.  **บทบาท (Roles)**: คือกลุ่มของสิทธิ์การใช้งาน เช่น "ผู้จัดการ", "พนักงานขาย", "ฝ่ายบัญชี" คุณสามารถสร้างบทบาทใหม่ได้ตามต้องการในหน้า `Settings > Roles & Permissions`
2.  **สิทธิ์ (Permissions)**: คือการกระทำเฉพาะอย่างที่ผู้ใช้สามารถทำได้ในระบบ เช่น `jobcard:create` (สิทธิ์ในการสร้าง Job Card) หรือ `customer:view:all` (สิทธิ์ในการดูลูกค้าทั้งหมด)
3.  **การกำหนดสิทธิ์**: คุณสามารถมอบหมายบทบาทให้กับผู้ใช้แต่ละคนได้ในหน้า `User Center` ผู้ใช้หนึ่งคนจะมีได้หนึ่งบทบาทต่อหนึ่ง Workspace

## รายการสิทธิ์ทั้งหมด

สิทธิ์ต่างๆ ถูกจัดกลุ่มตามโมดูลเพื่อง่ายต่อการจัดการ:

---

### Job Card

สิทธิ์ที่เกี่ยวข้องกับการสร้าง, ดู, และจัดการ Job Card บนบอร์ดงาน

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `jobcard:view:all` | **ดู Job Card ทั้งหมด**: ผู้ใช้สามารถเห็น Job Card ทั้งหมดในบอร์ดที่ตนเป็นสมาชิก |
| `jobcard:view:assigned` | **ดูเฉพาะ Job Card ที่ได้รับมอบหมาย**: ผู้ใช้จะเห็นเฉพาะ Job Card ที่ตนเองเป็นผู้รับผิดชอบเท่านั้น |
| `jobcard:create` | **สร้าง Job Card**: ผู้ใช้สามารถสร้าง Job Card ใหม่ได้ |
| `jobcard:edit:all` | **แก้ไขทุกฟิลด์ใน Job Card ทั้งหมด**: ผู้ใช้สามารถแก้ไขข้อมูลทุกอย่างใน Job Card ใดๆ บนบอร์ดได้ (เป็นสิทธิ์ระดับสูง) |
| `jobcard:edit:assigned` | **แก้ไขการ์ดที่ได้รับมอบหมาย**: ผู้ใช้สามารถแก้ไข Job Card ที่ตนเองเป็นผู้รับผิดชอบได้ |
| `jobcard:delete:all` | **ลบ Job Card ทั้งหมด**: ผู้ใช้สามารถลบ Job Card ใดๆ บนบอร์ดได้ |
| `jobcard:delete:assigned` | **ลบเฉพาะ Job Card ที่ได้รับมอบหมาย**: ผู้ใช้สามารถลบได้เฉพาะ Job Card ที่ตนเองเป็นผู้รับผิดชอบ |
| `jobcard:move` | **ย้าย Job Card**: ผู้ใช้สามารถย้าย Job Card ระหว่างเลนต่างๆ ได้ |

#### สิทธิ์การแก้ไขระดับฟิลด์ (Job Card)
ใช้ควบคุมการแก้ไขข้อมูลแต่ละส่วนในการ์ด เหมาะสำหรับบทบาทที่ต้องการจำกัดการแก้ไข

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `jobcard:edit:field:title` | แก้ไข: ชื่อเรื่อง |
| `jobcard:edit:field:description` | แก้ไข: คำอธิบาย |
| `jobcard:edit:field:status` | แก้ไข: สถานะ (Pending, In Progress, etc.) |
| `jobcard:edit:field:assignee` | แก้ไข: ผู้รับผิดชอบ |
| `jobcard:edit:field:collaborators` | แก้ไข: ผู้ร่วมงาน |
| `jobcard:edit:field:watchers` | แก้ไข: ผู้ติดตาม |
| `jobcard:edit:field:customer` | แก้ไข: ลูกค้าและบริษัท |
| `jobcard:edit:field:dates` | แก้ไข: วันที่เริ่มต้น/สิ้นสุด |
| `jobcard:edit:field:priority` | แก้ไข: ความสำคัญ |
| `jobcard:edit:field:hashtags` | แก้ไข: แฮชแท็ก |
| `jobcard:edit:field:todos` | แก้ไข: รายการสิ่งที่ต้องทำ (To-Do List) |
| `jobcard:edit:field:expenses` | แก้ไข: รายการค่าใช้จ่ายและการเงิน |
| `jobcard:edit:field:attachments` | แก้ไข: ไฟล์แนบ |
| `jobcard:edit:field:notes` | แก้ไข: บันทึกและความคิดเห็น |
| `jobcard:edit:field:customFields` | แก้ไข: ฟิลด์ที่กำหนดเอง |

### Customer Center (ลูกค้า)

สิทธิ์ในการเข้าถึงและจัดการข้อมูลลูกค้า

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `customer:view:all` | **ดูข้อมูลลูกค้าทั้งหมด**: ผู้ใช้สามารถดูข้อมูลลูกค้าทั้งหมดใน Workspace ได้ |
| `customer:view:assigned` | **ดูเฉพาะลูกค้าที่ได้รับมอบหมาย**: ผู้ใช้จะเห็นเฉพาะลูกค้าที่ตนเองเป็นผู้รับผิดชอบ |
| `customer:create` | **สร้างลูกค้า**: ผู้ใช้สามารถเพิ่มลูกค้าใหม่ได้ |
| `customer:edit:all` | **แก้ไขทุกฟิลด์ของลูกค้า**: ผู้ใช้สามารถแก้ไขข้อมูลลูกค้าทั้งหมดได้ (เป็นสิทธิ์ระดับสูง) |
| `customer:edit:assigned` | **แก้ไขลูกค้าที่ได้รับมอบหมาย**: อนุญาตให้แก้ไขข้อมูลของลูกค้าที่ตนเองรับผิดชอบ |
| `customer:delete` | **ลบลูกค้า**: ผู้ใช้สามารถลบข้อมูลลูกค้าได้ |
| `customer:import` | **นำเข้าข้อมูลลูกค้า**: ผู้ใช้สามารถนำเข้าข้อมูลลูกค้าจำนวนมากจากไฟล์ได้ |

### Company Center (นิติบุคคล)

สิทธิ์ในการจัดการโปรไฟล์บริษัท

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `company:view` | **ดูข้อมูลบริษัท**: ผู้ใช้สามารถดูโปรไฟล์บริษัททั้งหมดได้ (จำเป็นสำหรับการเชื่อมโยงลูกค้ากับบริษัท) |
| `company:create` | **สร้างบริษัท**: ผู้ใช้สามารถเพิ่มบริษัทใหม่ได้ |
| `company:edit` | **แก้ไขบริษัท**: ผู้ใช้สามารถแก้ไขข้อมูลบริษัทได้ |
| `company:delete` | **ลบบริษัท**: ผู้ใช้สามารถลบบริษัทได้ |
| `company:import` | **นำเข้าข้อมูลบริษัท**: ผู้ใช้สามารถนำเข้าข้อมูลบริษัทจำนวนมากจากไฟล์ได้ |

### Chat Center (ศูนย์แชท)

สิทธิ์ที่เกี่ยวข้องกับการเข้าถึงและจัดการการสนทนาใน Chat Center

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `chat:view:all` | **ดูแชททั้งหมด**: ผู้ใช้สามารถเห็นการสนทนาทั้งหมดใน Chat Center โดยไม่คำนึงถึงผู้รับผิดชอบ |
| `chat:view:assigned` | **ดูเฉพาะแชทที่ได้รับมอบหมาย**: ผู้ใช้จะเห็นเฉพาะการสนทนาที่ตนเองเป็นผู้รับผิดชอบเท่านั้น |
| `chat:view:unassigned` | **ดูแชทที่ยังไม่ได้มอบหมาย**: ผู้ใช้สามารถเห็นการสนทนาใหม่ที่ยังไม่มีเจ้าหน้าที่รับผิดชอบ |
| `chat:assign` | **มอบหมายแชท**: ผู้ใช้สามารถมอบหมายแชทให้เจ้าหน้าที่คนอื่นได้ |
| `chat:send` | **ส่งข้อความ**: ผู้ใช้สามารถส่งข้อความในการสนทนาที่ตนมีสิทธิ์เข้าถึงได้ |

### Product Management (สินค้า)

สิทธิ์ในการจัดการสินค้าและบริการ

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `product:view` | **ดูสินค้า**: ผู้ใช้สามารถดูสินค้าและบริการทั้งหมดได้ |
| `product:create` | **สร้างสินค้า**: ผู้ใช้สามารถเพิ่มสินค้าและบริการใหม่ได้ |
| `product:edit` | **แก้ไขสินค้า**: ผู้ใช้สามารถแก้ไขรายละเอียดสินค้าได้ |
| `product:delete` | **ลบสินค้า**: ผู้ใช้สามารถลบสินค้าได้ |
| `product:import` | **นำเข้าสินค้า**: ผู้ใช้สามารถนำเข้าข้อมูลสินค้าจำนวนมากจากไฟล์ได้ |

### Sales Documents (เอกสารการขาย)

สิทธิ์ที่เกี่ยวข้องกับใบเสนอราคา, ใบแจ้งหนี้, และใบเสร็จรับเงิน

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `quotation:create` | **สร้างใบเสนอราคา**: ผู้ใช้สามารถสร้างใบเสนอราคาใหม่ได้ |
| `quotation:edit` | **แก้ไขใบเสนอราคา**: ผู้ใช้สามารถแก้ไขใบเสนอราคาที่ยังไม่ถูกล็อคได้ |
| `quotation:delete` | **ลบใบเสนอราคา**: ผู้ใช้สามารถลบใบเสนอราคาที่ยังไม่ถูกล็อคได้ |
| `quotation:revise` | **แก้ไขใบเสนอราคา (Revise)**: อนุญาตให้เปลี่ยนสถานะเอกสารที่ส่งแล้วกลับเป็นฉบับร่างเพื่อแก้ไข |
| `invoice:create` | **สร้างใบแจ้งหนี้**: ผู้ใช้สามารถสร้างใบแจ้งหนี้ใหม่ได้ (รวมถึงการสร้างจากใบเสนอราคา) |
| `invoice:edit` | **แก้ไขใบแจ้งหนี้**: ผู้ใช้สามารถแก้ไขใบแจ้งหนี้ที่ยังไม่ถูกล็อคได้ |
| `invoice:delete` | **ลบใบแจ้งหนี้**: ผู้ใช้สามารถลบใบแจ้งหนี้ที่ยังไม่ถูกล็อคได้ |
| `receipt:create` | **สร้างใบเสร็จ**: ผู้ใช้สามารถสร้างใบเสร็จจากใบแจ้งหนี้ได้ |
| `receipt:edit` | **แก้ไขใบเสร็จ**: ผู้ใช้สามารถแก้ไขใบเสร็จที่ยังไม่ถูกล็อคได้ |
| `receipt:delete` | **ลบใบเสร็จ**: ผู้ใช้สามารถลบใบเสร็จที่ยังไม่ถูกล็อคได้ |

### Approvals (การอนุมัติ)

สิทธิ์ที่เกี่ยวข้องกับระบบการอนุมัติเอกสาร

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `approval:act` | **ดำเนินการอนุมัติ**: อนุญาตให้ผู้ใช้อนุมัติหรือปฏิเสธรายการที่ถูกส่งมาให้ตนเอง |
| `approval:override` | **แทนที่เวิร์กโฟลว์**: อนุญาตให้ผู้ใช้ข้ามข้อจำกัดของเวิร์กโฟลว์ (เช่น เปลี่ยนสถานะขณะรออนุมัติ) **(โปรดให้สิทธิ์นี้ด้วยความระมัดระวัง)** |

### Settings (การตั้งค่า)

สิทธิ์ในการเข้าถึงและจัดการส่วนต่างๆ ของหน้าตั้งค่าระบบ

| สิทธิ์ | คำอธิบาย |
| :--- | :--- |
| `settings:board:manage` | **จัดการการตั้งค่าบอร์ด**: ผู้ใช้สามารถแก้ไขรายละเอียดบอร์ด, เลน, และฟิลด์ที่กำหนดเองได้ |
| `settings:company:manage` | **จัดการการตั้งค่าบริษัท**: ผู้ใช้สามารถแก้ไขแหล่งที่มาของลูกค้า, เทมเพลต To-Do, ฯลฯ |
| `settings:id:manage` | **จัดการกฎการสร้าง ID**: ผู้ใช้สามารถกำหนดค่ากฎการสร้าง ID อัตโนมัติได้ |
| `settings:catalog:manage` | **จัดการการตั้งค่าแคตตาล็อก**: ผู้ใช้สามารถกำหนดค่าแคตตาล็อกสินค้าสาธารณะได้ |
| `settings:roles:manage` | **จัดการบทบาทและสิทธิ์**: สิทธิ์สำคัญในการสร้าง, แก้ไข, และลบบทบาท **(โปรดให้สิทธิ์นี้ด้วยความระมัดระวังอย่างยิ่ง)** |
| `settings:documents:manage` | **จัดการการตั้งค่าเอกสาร**: ผู้ใช้สามารถจัดการเทมเพลต, หมายเหตุ, และลายเซ็นเริ่มต้นสำหรับเอกสารทั้งหมด |
| `settings:approvals:manage` | **จัดการการตั้งค่าการอนุมัติ**: ผู้ใช้สามารถสร้าง, แก้ไข, และลบเวิร์กโฟลว์การอนุมัติได้ |

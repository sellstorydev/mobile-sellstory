# สิทธิ์การมองเห็นรายการแชท (Chat Center Visibility)

ระบบการมองเห็นแชทใน Chat Center ถูกควบคุมโดยสิทธิ์ (Permissions) 3 รูปแบบ ซึ่งจะกำหนดว่าผู้ใช้แต่ละคนจะสามารถเห็นแชทของใครได้บ้าง สิทธิ์เหล่านี้สามารถตั้งค่าได้ในหน้า Roles & Permissions

## ภาพรวมสิทธิ์ (Permission Overview)

1.  **`chat:view:all` (ดูแชททั้งหมด)**
    *   **ความสามารถ:** ผู้ใช้ที่มีสิทธิ์นี้จะสามารถมองเห็น **ทุกแชท** ใน Workspace ได้ ไม่ว่าจะถูกมอบหมายให้ใครก็ตาม
    *   **เหมาะสำหรับ:** ผู้ดูแลระบบ, ผู้จัดการทีม, หรือหัวหน้าเซลล์ที่ต้องการดูแลภาพรวมทั้งหมด

2.  **`chat:view:assigned` (ดูเฉพาะแชทที่ได้รับมอบหมาย)**
    *   **ความสามารถ:** ผู้ใช้จะเห็นเฉพาะแชทที่ถูกมอบหมาย (Assign) ให้กับ **ตนเองเท่านั้น**
    *   **เหมาะสำหรับ:** พนักงานขายทั่วไป (Salesperson) หรือเจ้าหน้าที่ที่ดูแลลูกค้าของตัวเอง

3.  **`chat:view:unassigned` (ดูแชทที่ยังไม่ได้มอบหมาย)**
    *   **ความสามารถ:** ผู้ใช้จะสามารถเห็นแชทใหม่ที่เข้ามาในระบบและ **ยังไม่ถูกมอบหมาย** ให้กับเจ้าหน้าที่คนใด
    *   **เหมาะสำหรับ:** พนักงานที่ทำหน้าที่คัดกรองและจ่ายงาน (Triage) หรือหัวหน้าทีมที่ต้องการกระจายแชทใหม่ๆ

## ตัวอย่างการตั้งค่า (Configuration Examples)

คุณสามารถผสมผสานสิทธิ์เหล่านี้เพื่อให้ได้ผลลัพธ์ตามที่ต้องการ:

| บทบาท (Role)                 | สิทธิ์ที่ควรตั้งค่า                               | ผลลัพธ์ที่ได้                                                                                             |
| ----------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **ผู้ดูแลระบบ / หัวหน้าทีม**  | `chat:view:all`                                      | เห็นทุกการสนทนาในระบบ                                                                                     |
| **พนักงานขาย (ทั่วไป)**        | `chat:view:assigned`                                 | เห็นเฉพาะแชทที่ตัวเองดูแลอยู่เท่านั้น                                                                      |
| **เจ้าหน้าที่คัดกรองแชท**     | `chat:view:assigned`<br/>`chat:view:unassigned`     | เห็นแชทของตัวเอง และเห็นแชทใหม่ที่ยังไม่มีเจ้าของ เพื่อนำไปมอบหมายต่อ                                        |
| **พนักงานขายที่ช่วยกันดูแล** | `chat:view:assigned`<br/>`chat:view:unassigned`     | เหมือนกับเจ้าหน้าที่คัดกรอง แต่ทุกคนในทีมที่มีสิทธิ์นี้จะเห็นแชทใหม่ที่เข้ามาพร้อมกัน |

**ข้อควรจำ:**
*   หากผู้ใช้มีสิทธิ์ `chat:view:all` สิทธิ์อื่นๆ (assigned, unassigned) จะไม่มีผล เพราะสามารถเห็นทุกอย่างได้อยู่แล้ว
*   การไม่มีสิทธิ์ `chat:view:*` ใดๆ เลย จะทำให้ผู้ใช้ไม่สามารถเห็นแชทใดๆ ใน Chat Center ได้
